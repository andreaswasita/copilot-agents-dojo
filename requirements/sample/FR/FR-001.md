# FR-001 — Auto-classify EN/ZH documents on ingest

## User Story

As an operations analyst,
I want incoming EN/ZH documents to be classified into one of five
categories on ingest,
so that downstream extraction pipelines run without manual triage.

## Acceptance Criteria

- Given an English-language permit PDF, when it is ingested, then the
  pipeline assigns category `permit` and routes it to the permit
  extraction queue.
- Given a Simplified-Chinese geological report, when it is ingested,
  then the pipeline assigns category `geological-report` and routes it
  to the geological queue.
- Given a document whose category cannot be determined with
  confidence ≥ 0.80, when it is ingested, then it is routed to a
  human review queue with the top three candidate categories attached.

## Out of Scope

- Traditional Chinese documents (separate engagement).
- Hand-written annotations on scanned documents.
