# TR-001 — GPU inference fleet for classification

## Technical Requirement

A regional GPU inference fleet for the bilingual classification model.
Minimum baseline of four NVIDIA L4-class accelerators per active
region, autoscaling between four and twelve nodes based on ingest
queue depth.

## Justifying Parents

- **NFR-001** — latency budget for classification (p95 < 2s) only
  holds with on-fleet inference, not a shared inference endpoint.
- **NFR-002** — accuracy floor requires the production model size
  (~7B parameters) which does not fit in CPU latency budget.
- **IR-001** — ingest contract commits to 202 within 250ms; the
  remaining latency budget for classification implies sub-second
  inference.

## Cost Anchor

Estimated steady-state cost: AUD 6,800 / region / month at the 4-node
floor. Per-document cost contribution: AUD 0.18, well inside the
30%-reduction lever in BR-001.
